**① 维度命名（根因 B 的实证）**

## 四、测试中发现的环境问题（非模组 bug）

1. **`online-mode=false` + `enforce-secure-profile=true` 会让离线客户端卡在连接界面**
   服务端 18 秒后报 `lost connection`，客户端停在 `Connecting to...` 不再有日志。
   改为 `enforce-secure-profile=false` 后立即正常。
   → 若用离线账号测试/开服，这两项必须配对。已恢复为原值，请按需调整。

2. **客户端所在的 JVM 无法验证 Mojang 证书**（`PKIX path building failed`）
   导致 `YggdrasilServicesKeyInfo: Failed to request yggdrasil public key`。
   与本次模组功能无关，但会连带影响聊天签名。

3. **`compileJava` 需要绕过本机失效代理**
   见工程根目录说明；`127.0.0.1:7890` 未启动且 JDK cacerts 校验 `libraries.minecraft.net` 失败。

4. **`sectors.json` 里 `lobby` 与 `wait` 可以是不同世界**（本次未改动），
   但在实例化方案下这会强制每次复活都跨维度，建议后续统一。

## 五、未覆盖项与建议补测

| 项 | 原因 | 建议 |
|---|---|---|
| 部署包校验（`C2SDeployRequest`） | 需要客户端按键触发，RCON 无法伪造自定义包 | 用客户端按 U → DEPLOY 各试一次：战斗中存活/阵亡/非对局三种情况 |
| 计分隔离 | 需要两个 arena 同时跑完一局 | 两批玩家分别 `bt join area_alpha` / `area_bravo`，让 A 局打完看 B 局分数 |
| 信标复活 | 需要玩家实际放置信标 | 给玩家 `respawn_beacon` 物品，放置后队友阵亡观察落点 |
| 背包还原的**内容**一致性 | 已确认快照被消费，未逐格比对物品 | 带可识别物品（命名牌/附魔）入局，退局后逐格核对 |
| 多实例世界 | 不属于本轮修复范围 | 按 `docs/战地模式-游戏世界实例化方案.md` 的阶段 0 先做技术验证 |
