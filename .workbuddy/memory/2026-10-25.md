## 重新部署界面（Redeploy）重做完成

产出 `docs/战地模式-重新部署界面-设计与实施.md`。

**结构**：新增 `deploy/` 包（Option/Target/Context/Data/Rules + 突破模式实现），
规则是纯函数（不引用任何 MC 类型）→ 可单元测试；arena 配置新增 `"gameMode"`（默认 breakthrough）。
网络换成 `S2CDeployDataPacket` / `C2SRequestDeployData` / `S2CDeployResultPacket`，
`C2SDeployRequest` 由 spawnIndex 改 optionId（`base` / `point:A` / `beacon:<uuid>`），PROTOCOL 升到 "4"。
客户端 `client/deploy/` 5 个类 + `client/ui/RedeployScreen`，旧 `RespawnDeployScreen` 与
只注册从不发送的 `S2COpenDeployScreenPacket` 已删。

**关键实证（务必记住）**：
1. **`doImmediateRespawn=true` 会让客户端跳过死亡界面直接自动复活** → 部署界面永远出不来。
   客户端这个开关只来自 `ClientboundLoginPacket.showDeathScreen`，运行时只能靠
   `ClientboundGameEventPacket(IMMEDIATE_RESPAWN, 0F)` 改。现在进场时发 0、离场按世界规则还原。
2. `LivingDeathEvent` 早于 `ClientboundPlayerCombatKillPacket`，死亡当场发部署包会被死亡界面盖住，
   必须排到下一 tick。
3. 服务端强制复活用 `PlayerList#respawn`（与客户端点"重生"同一路径），但复活的 ServerPlayer 是新实例，
   回包要用 `getPlayerList().getPlayer(uuid)` 重新取，不能拿旧引用。
4. 原实现 `onPlayerRespawn` 复活后不下发配装（只有存活部署时才下发）——本次补上。

**实机结果**：阵亡→界面自动打开（顶部战局栏/左侧列表/战区图/右侧配置/底部按钮齐全）→
回车部署→服务端 `pending=base` 复活回攻方出生点，票数 299，闭环通过。
截图在 `docs/screenshots/deploy/`。

**测试**：新增 JUnit 5（build.gradle 里加依赖 + useJUnitPlatform），12 个用例全绿
（8 个规则 + 4 个包编解码）。未覆盖：双人/多局、队友信标部署、真实鼠标点击（后台窗口鼠标事件会被 GLFW 丢弃）。

**遗留**：兵种、队友个体部署、载具、征服/突袭/TDM 只有扩展点没有实现；
真实底图仍是"坐标投影示意图"。

## 部署界面底图（服务端烘焙）已实现并实机验证

**做法**：不依赖美术资源。模板就是 `config/battlefield/templates/<id>/region` 的 .mca，
`TemplateStore` 已把它解析成内存里的 `PalettedContainer`，所以直接在后台线程采样：
每列自上而下找第一个非空气方块 → 取 `MapColor.col` → 东侧高度差做山体阴影 → `ImageIO` 出 PNG。

新增：`deploy/map/` 4 个类（Raster 纯几何 / BakedDeployMap / TemplateMapBaker / DeployMapService）
+ `S2CDeployMapPacket` / `C2SRequestDeployMap` + `client/deploy/DeployMapTexture`。
`DeploymentData` 加 `mapId`，PROTOCOL 升到 "5"。

**实测**（Mohist）：179x99、3 格/像素、烘焙 15ms、PNG 15KB；截图 `docs/screenshots/deploy/13-redeploy-basemap.png`
显示真实地形（草地/水域/沙滩/建筑）+ 网格刻度，标记与地形对齐。
配置项：`deployMapBakeEnabled` / `deployMapBlocksPerPixel`(3) / `deployMapMaxPixels`(320)。

**踩坑**：
1. **不要在服务端运行时覆盖 mods 里的 jar**——Mohist 会把 jar 当模块目录，覆盖后 `ClassNotFoundException`
   直接把服务端 stop 掉。必须先 stop 再换 jar。
2. 底图按 `mapId = 模板 id + 指纹 + 精度 + 栅格哈希` 缓存；槽位平移只改边界不改像素，多槽位共用一张图。
3. 静态世界（无模板）没有区块数据可采样 → 按设计降级成坐标示意图。

测试：21 项全绿（8 规则 + 4 数据包 + 6 栅格几何 + 3 底图导出）。
